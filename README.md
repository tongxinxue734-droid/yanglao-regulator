# 养老机构安全监管平台

基于 Streamlit 的一体化 **「安全巡检 - 整改 - 复盘 - 考核」全链路** 系统，内置《养老机构运营违规评价指标》
（41 条，A 主体资格 / B 设施安全 / C 人员配备 / D 服务规范 / E 制度管理 / F 资金收费）与综合扣分处罚档次。

> 平台定位：**西安市民政局（市—区县两级）养老机构智慧监管平台**。面向政府监管人员（一级·市民政局 / 二级·区县民政局 / 三级·检查员），覆盖机构监管、补贴监管、服务质量监管三条主线；演示机构数据全部为西安市各区县口径（雁塔/莲湖/碑林/未央/长安/灞桥/新城/临潼），政策依据引用《西安市养老服务促进条例》。

## 多机构评分体系（监管视角）

系统面向**监管方**，对辖区多个养老机构进行 100 分制月度评分：

- 内置 8 个**西安区县虚拟机构**（演示数据，地址仅到区/路段、电话截断、法人打码，符合政务数据脱敏规范）
- 每个机构独立检查打分：发现违规 → 按 39 条指标扣分（1/2/3/6/9/12）→ 机构得分 = 100 − 当月累计扣分 → 自动映射综合处罚档次
- **每月更新**：机构月度得分随检查记录自动重算
- **月度报告**：每机构每月生成（核心指标/扣分明细/隐患分布/未闭环明细/改进建议）
- **年度总报告**：每机构每年生成（12 个月趋势/全年扣分根因/年度得分/档次）
- 报告导出带机构抬头、公章位、签字栏；报告标注 **AIGC 生成标识**（符合 2025 AIGC 内容标识规范）

> 数据安全红线：系统不采集身份证号、门牌地址、银行/社保/医保账号等敏感字段；操作全程留痕（审计日志）；AI 辅助生成内容按规范标识。

## 快速开始

```bash
pip install -r requirements.txt
streamlit run app.py
```

或直接双击 **`启动系统.bat`**（自动启动服务并打开浏览器，手机可 PWA 添加到桌面）。

浏览器访问 `http://localhost:8501`。

## 界面设计（Liquid Glass 风格）

采用 **Liquid Glass（液态玻璃）设计系统**：深色科技底（`#0F172A` 渐变光晕）+ 磨砂玻璃卡片（`backdrop-blur 20px` + 半透明边框 + 顶部反射光）+ Fira Sans/Code 字体 + SVG 图标库（Lucide 风格，无 emoji）。状态色语义化：红/橙/黄/蓝四级风险、绿=闭环。图表统一 Plotly 深色主题，卡片 hover 抬升 + 渐变光效。设计令牌与组件集中在 `views/theme.py`，全局 CSS 一次性注入。

## 目录结构

```
app.py               # 入口：初始化、角色化导航、页面分发
config.py            # 常量：隐患分级、处罚档次、预警规则、AI 开关
models.py            # SQLAlchemy 12 张表
indicators.py        # 内置 39 条《养老机构运营违规评价指标》
seed.py              # 幂等种子数据（账号/空间/演示闭环/评分）
auth.py              # 登录 + 三级行级权限过滤
services/
  accounts.py        # 账号管理（权限约束）
  ai_vision.py       # AI 视觉识别（offline 演示 / api 可插拔）
  voice.py           # 语音要素结构化（位置/类型/紧急程度）
  watermark.py       # 照片水印 + 感知哈希去重
  scoring.py         # 合规得分、处罚档次、排行榜、智能预警
  reports.py         # 月度/年度统计、Excel/HTML 导出
views/               # 14 个页面（含分析中心）+ 设计系统
  theme.py           # Liquid Glass 设计系统（CSS/SVG 图标/玻璃组件）
  analytics.py       # 分析中心（SLA/时间轴/雷达/预测）
data/                # SQLite 库、照片、报告（运行时生成）
```

## AI 能力接入（生产环境）

`config.py` 中 `AI_MODE` 默认 `offline`（演示模拟识别）。切换 `api` 并配置
`VISION_API_URL` / `VOICE_API_URL` 即可接入第三方视觉大模型与 Whisper/讯飞语音转写，
无需改业务代码；隐私要求高的场景可在本地部署 YOLOv8 + faster-whisper。

## 部署建议

- 小规模试用：内网直接 `streamlit run app.py`
- 正式使用：Docker 打包 + Nginx 反向代理 + HTTPS；数据库建议切换 PostgreSQL（改 `config.DATABASE_URL`）
- 备份：每日备份 `data/safety.db`，照片定期归档
- 推送：配置企业微信机器人 webhook（`WECHAT_WEBHOOK_URL`）后可在消息中心联动推送
